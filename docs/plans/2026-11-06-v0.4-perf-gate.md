# Retake v0.4 Performance gate: Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [x]` for tracking.

**Goal:** Build everything the v0.4 gate needs except playing the route: the config knobs the measurements switch between, a one-command `scripts/bench.ps1` that captures frame times and resource use and prints baseline-vs-config deltas, and `docs/perf.md` to hold the route, environment and results.

**Architecture:** Two new config keys (`capture.preset`, `capture.priority`) let a bench run change the encoder preset and ffmpeg's CPU priority without a rebuild. Measurement is PowerShell: `scripts/perf-stats.ps1` holds pure, dot-sourceable functions (frame-time stats, deltas, the gate, the table) with a plain-assert test file run in CI; `scripts/bench.ps1` orchestrates Retake, PresentMon and Windows perf counters and saves every raw file so `-Report` can recompute any table later.

**Tech stack:** Rust stable (as before); PowerShell 7; PresentMon 2.6.0 console (`PresentMon-2.6.0-x64.exe`, SHA-256 `b2a706bc6ad475749e3b7e3409263aa1e6906d45bdcf993f6dbc0f660188f1af`, from the GitHub release's digest); ffmpeg 9.0.2.

Source: roadmap tab **v0.4 Performance gate**. Anti-cheat rules (v0.8 tab) apply.

## Global Constraints

- All v0.1–v0.3 constraints hold: `retake-core` has no `windows` dependency; CI = fmt, `forbidden-apis.ps1`, clippy `-D warnings`, tests, release build; config errors read `<section>.<field> = <value>: <reason>`.
- Anti-cheat: nothing opens Siege's process. The bench reads Siege's frame times through PresentMon (ETW, no process handle) and its GPU use through Windows perf counters, by process name/PID.
- Gate: average FPS loss ≤ 3% and 1% low loss ≤ 5%, each on the mean of a config's runs vs the mean of the baseline runs.
- Defaults stay as they are (`preset = "speed"`, `priority = "normal"`, QP 16/18) until measured.
- The test copy of Retake recording the desktop (the soak) must not be disturbed: no live recording before 20:08 UTC on 2026-11-06.
- Commits local on `feat/v0.4-perf-gate` (stacked on PR #10's `fix/amf-bgra-ffmpeg-9`); push and PR only with the user's OK.

## Decisions (flagged)

1. **PresentMon instead of CapFrameX.** CapFrameX is PresentMon under a GUI and needs a hotkey and JSON export; PresentMon's console exe captures a fixed 60 s with `--timed 60 --terminate_after_timed` straight to CSV, so the script runs each capture itself. The user is in *Performance Log Users*, so no admin is needed. Fetched by `scripts/fetch-presentmon.ps1`, pinned by SHA-256 like ffmpeg.
2. **AV1 runs are dropped from this gate.** PR #10 refuses `codec = "av1"` (clips can't be saved from AV1 in MPEG-TS), so an AV1 number would measure a mode nobody can use. `docs/perf.md` says so; AV1 is measured when it becomes saveable.
3. **Metric definitions** (match CapFrameX's defaults): frame time = `MsBetweenPresents`; average FPS = frames ÷ total seconds; 1% low = 1000 ÷ the 99th-percentile frame time (nearest rank); 0.1% low = same at 99.9th; spikes = frames over 2× the median frame time.
4. **Resource use from perf counters, not HWiNFO:** per second, `\GPU Engine(*)\Utilization Percentage` summed by engine type for the game PID (`3d`) and the ffmpeg PID (`3d`, `video codec*`), `\GPU Process Memory(*)\Dedicated Usage` for ffmpeg, and `\Process(...)\% Processor Time` for `ffmpeg` and `retake` (÷ logical CPUs). On this PC the encoder engine shows as `video codec engine`.
5. **Bitrate and disk writes** from the buffer: the bench reads ffmpeg's command line (CIM `Win32_Process`, ffmpeg is Retake's own child) for `-segment_list`, then bytes of the closed segments in `index.csv` ÷ their duration → Mbit/s and GB/hour.
6. **`capture.preset`** = `"speed" | "balanced" | "quality"` maps per encoder: AMF `-quality speed|balanced|quality`; QSV `-preset veryfast|medium|veryslow`; NVENC `-preset p1|p4|p7`. **`capture.priority`** = `"normal" | "below_normal"` sets the recording ffmpeg's CPU priority class. GPU scheduling priority (`D3DKMTSetProcessSchedulingPriorityClass`) is left out: the roadmap says "if needed", and it is only needed if the gate fails.
7. **The bench restarts Retake per config** with a small `config.toml` holding only the changed keys (Retake merges it over the defaults), and puts the user's own `config.toml` back afterwards, even on Ctrl+C.

### Task 3: frame-time stats, deltas and the gate (`perf-stats.ps1`)

**Files:**
- Create: `scripts/perf-stats.ps1`, `scripts/perf-stats.tests.ps1`
- Modify: `.github/workflows/ci.yml` (step after Forbidden APIs: `name: Bench stats tests`, `shell: pwsh`, `run: ./scripts/perf-stats.tests.ps1`)

**Interfaces:**
- Produces (dot-source `. scripts/perf-stats.ps1`):
  - `Read-FrameTimes -Path <csv> [-Process <name>]` → `[double[]]` of `MsBetweenPresents` (rows whose `Application` matches when `-Process` is given; skips `NA` and values ≤ 0, which PresentMon writes for a swap chain's first frame).
  - `Get-FrameStats -FrameTimes <double[]>` → `[pscustomobject]@{ Frames; Seconds; AvgFps; Low1; Low01; Spikes; MedianMs }`.
  - `Get-RunMean -Stats <object[]>` → same shape, each field the mean.
  - `Get-Delta -Baseline <double> -Value <double>` → percent change (`(v-b)/b*100`).
  - `Test-Gate -Baseline <stats> -Config <stats>` → `[pscustomobject]@{ AvgLossPct; Low1LossPct; Pass }` (loss = −delta; pass when avg ≤ 3 and low1 ≤ 5).
  - `Get-BufferRate -IndexCsv <path>` → `[pscustomobject]@{ Mbps; GBPerHour; Segments }` from rows `name,start,end` and the files' sizes beside it.
  - `Format-ResultTable -Rows <object[]>` → markdown string, columns `Config | Runs | Avg FPS | Δ avg | 1% low | Δ 1% | 0.1% low | Spikes | Gate`.

- [x] **Step 1: Write the tests** (`perf-stats.tests.ps1`: dot-sources the module, a tiny `Assert-Equal($name, $want, $got, $tol)` that throws, a counter, exit 1 on any failure):

Assert-Equal 'seconds' 5.2 $s.Seconds 1e-9
Assert-Equal 'avg fps' (1010 / 5.2) $s.AvgFps 1e-6
Assert-Equal 'low1' 200 $s.Low1 1e-9            # rank ceil(0.99*1010)=1000 -> 5 ms
Assert-Equal 'low01' 50 $s.Low01 1e-9           # rank ceil(0.999*1010)=1009 -> 20 ms
Assert-Equal 'spikes' 10 $s.Spikes 0            # 20 > 2*5
Assert-Equal 'delta' -2.5 (Get-Delta 200 195) 1e-9

Assert-Equal 'avg loss' 2.5 $g.AvgLossPct 1e-9; Assert-Equal 'low loss' 6 $g.Low1LossPct 1e-9; Assert-Equal 'gate' $false $g.Pass 0
