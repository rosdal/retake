# v0.7 Grading & export Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [ ]` for tracking.

**Goal:** every saved clip gets an automatic, constant per-clip grade baked into one 3D LUT and rendered in 10-bit; export presets and optional motion blur are made from the graded clip; all of it runs after the game closes.
**Architecture:** pure math in `retake-core::grade` (cube I/O, tetrahedral lookup, histogram stats with a HUD mask, correction with low-key guard, capped white balance, contrast, vibrance, LUT composition, the built-in look) and `retake-core::export` (grade render and preset command lines, motion-blur weights). `retake-core::queue` persists jobs. In the binary, `grader.rs` runs ffmpeg/ffprobe and `media.rs` feeds the queue to the quiet-mode background runner one job at a time.
**Tech stack:** ffmpeg 9.0.2 filters `lut3d`, `cas`, `tmix`, `amix`; `hevc_amf`/`hevc_nvenc`/`hevc_qsv` Main10; `serde_json`.

## Global Constraints

- A failed grade never deletes or changes a raw clip: write to `clips/tmp/`, check with ffprobe (duration within 0.1 s, same audio track count), then rename.
- Nothing runs while the game runs (background runner + quiet gate).
- Grades are constant per clip (no per-frame adaptation).
- Colour: BT.709 limited range in and out, tagged on every file Retake writes.
- `edit` exports never get motion blur.

## Deviations from the roadmap (decided here)

- **Built-in look made in code, not in Resolve.** `builtin_look()` is a gentle contrast + vibrance + split-tone + soft shoulder LUT, the recipe the roadmap describes, generated at build time. It is checked on real Siege footage (the SteelSeries clips in `Videos/`) instead of four freshly recorded reference clips. A user `.cube` still works via `grade.look`.
- **Regrade… / Blur… dialogs** need the v0.9 window; v0.7 ships "Regrade last clip" and "Export pending now" in the tray.
- `export.when = "immediately"` is dropped: exports never run during a match.

## Tasks

1. `retake-core::grade` + tests (identity at amount 0, low-key guard, WB cap, cube round trip, tetrahedral identity, HUD mask). 
2. `retake-core::export` + tests (grade render, HUD protect, each preset, blur weights).
3. `retake-core::queue` + tests (order, retry once, manual gating, JSON round trip).
4. Config: `[grade]`, `[export]`, `[motion_blur]`, `clips.max_raw_gb`, with validation.
5. `grader.rs` + `media.rs` + tray items; startup check that the look LUT loads.
6. Capture colour tags (`-colorspace bt709 … -color_range tv`) after measuring what the encoders produce from desktop RGB.
7. Live checks: grade 4 real Siege clips (indoor, outdoor, dark, smoke), stills before/after into `docs/grade/`; queue survives a restart; overwrite safety (kill mid-grade, raw survives); speed of a 20 s 1440p clip; each preset plays.
