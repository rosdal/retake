# Retake v0.2 — Video Ring Buffer Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [ ]` for tracking.

**Goal:** While Siege runs, ffmpeg continuously writes 2 s HEVC segments into a rolling 60 s buffer; recording stops when the game closes and ffmpeg is restarted if it crashes. Video only.

**Architecture:** All decisions are pure code in `retake-core`: the ffmpeg argument builder, the stats-line parser and speed monitor, the session state machine (`Idle → Starting → Recording → Stopping → Idle`, plus `Failed`), the monitor check and the buffer-folder rules. The `retake` binary adds thin Win32 glue (Toolhelp process snapshot, DXGI/`EnumDisplaySettingsW` monitor list, drive type and free space), an `Ffmpeg` process wrapper with graceful `q` stop, and a recorder thread that drives the state machine on a 250 ms tick and posts the tray status to the main thread.

**Tech stack:** Rust stable (MSVC), crates already in `Cargo.lock`; `windows` 0.62 gains the features `Win32_System_Diagnostics_ToolHelp`, `Win32_Storage_FileSystem`, `Win32_System_ProcessStatus`, `Win32_Graphics_Dxgi_Common`. Pinned ffmpeg (8.0.1 gyan full in `third_party/ffmpeg/`).

Source of requirements: roadmap doc *Retake — Roadmap v0.0 → v1.0*, tab **v0.2 Video ring buffer**; the **Anti-cheat safety** tab applies to every version.

## Global Constraints

- Everything from the v0.1 plan's Global Constraints still holds (target, `retake-core` has no `windows` dependency, CI commands, config error format `<section>.<field> = <value>: <reason>`).
- Game process detection: `CreateToolhelp32Snapshot` only. Never `OpenProcess` on any process that isn't our own ffmpeg child (anti-cheat rule 1).
- Capture: `ddagrab` (DXGI Desktop Duplication) only (rule 2). No overlays, no in-game popups, so **no toasts during v0.2** (rule 6); status is shown by the tray icon and tooltip only.
- Forbidden identifiers in source (CI-enforced from Task 6): `ReadProcessMemory`, `WriteProcessMemory`, `VirtualAllocEx`, `CreateRemoteThread`, `SetWindowsHookEx`, `SendInput`, `keybd_event`, `mouse_event`, `NtReadVirtualMemory`, `PROCESS_VM_READ`, `PROCESS_ALL_ACCESS`.
- Timings: process poll 2 s; start debounce 5 s; stop debounce 5 s; restart backoff 1 s, 2 s, 5 s (5 s thereafter); 5 restarts within 10 minutes → `Failed` until the next game launch; graceful stop = write `q` to stdin, wait 3 s, then `TerminateProcess`; "encoder falling behind" when `speed` < 0.98 for 10 s.
- Segments: `seg_00.ts`… in `buffer_dir`, 2 s each, `ceil(buffer_secs / 2)` of them, MPEG-TS, keyframe every `fps * 2` frames, `-bf 0`. Index `buffer_dir\index.csv` (CSV: filename, start, end), bounded with `-segment_list_size` = segment count.
- ffmpeg must **not** get `-nostdin` (stdin carries `q`).
- Tray colours: grey = idle, red = recording, yellow = warning or failed.
- Free-space warning threshold: 5 GB (5 × 1024³ bytes). Network, removable and CD drives are refused for `buffer_dir`.

## Decisions made while planning (flagged)

1. **Bounded index.** `-segment_list_size {count}` keeps `index.csv` at the last `count` entries; checked by hand with the pinned ffmpeg (wrap 3, 14 s of input → exactly 3 rows, times absolute: `seg_01.ts,8.0,10.0` …). No daemon-side trimming needed.
2. **"Empty buffer_dir" deletes only Retake's own files** (`seg_*.ts`, `index.csv`), not everything in the folder. A user who points `buffer_dir` at an existing folder must not lose files.
3. **Segment count rounds up** (`buffer_secs.div_ceil(2)`), so an odd `buffer_secs` still covers the whole buffer.
4. **New config rule:** `capture.buffer_dir` must not contain `%`, because it becomes part of ffmpeg's `seg_%02d.ts` pattern.
5. **Progress lines:** `-loglevel warning -stats -stats_period 1`. ffmpeg's warnings and errors go to the log at `warn`; stats lines are parsed and not logged one by one. A summary (fps, speed, ffmpeg working set) is logged every 60 s, which also gives the soak test its RAM numbers.
6. **Monitor index = DXGI output index on adapter 0**, the adapter `-init_hw_device d3d11va` picks by default. Resolution and refresh rate come from `EnumDisplaySettingsW` (physical mode), name and colour space from `IDXGIOutput6::GetDesc1`.
7. **Startup checks are fatal** (like other config errors): `capture.output` out of range, buffer drive of the wrong kind. Refresh-rate and HDR problems are warnings (log + yellow icon).
8. **Ffmpeg crashed into `Starting`**: a game that exits during the 5 s debounce goes back to `Idle` without ffmpeg ever starting. A spawn failure counts as an ffmpeg exit, so it also backs off and can end in `Failed`.
9. **This dev machine has no AMD GPU** (Intel Arc + NVIDIA). AMF encoding, `ddagrab` on a real game, and every Siege test are manual tests on the gaming PC. What can run here does: unit tests, an opt-in integration test of the segmenter + graceful stop using `lavfi`/`libx264`, and a dry run with `game.processes = ["notepad.exe"]` that exercises start/stop and the crash-backoff path (AMF fails to open here, which is exactly a crash loop).
10. **Push/PR** is outward-facing; local commits on `feat/v0.2-ring-buffer`, then push and open the PR only with the user's OK.

```rust
//! The ffmpeg command line for the ring buffer, built from `[capture]`. Pure, so the exact
//! arguments are pinned by tests.

use crate::config::{Capture, Codec};

/// Length of one buffer segment, in seconds.
pub const SEGMENT_SECS: u32 = 2;
/// The CSV segment list (filename, start, end) inside `buffer_dir`.
pub const INDEX_FILE: &str = "index.csv";
/// ffmpeg's output pattern inside `buffer_dir`.
pub const SEGMENT_PATTERN: &str = "seg_%02d.ts";

/// Segments needed to hold `buffer_secs`, rounded up.
pub fn segment_count(buffer_secs: u32) -> u32 {
    buffer_secs.div_ceil(SEGMENT_SECS)
}

fn strs(a: &[&str]) -> Vec<String> {
    a.iter().map(|s| (*s).to_owned()).collect()
}

/// Desktop Duplication of monitor `output` at `fps`, without the cursor.
pub fn input_args(c: &Capture) -> Vec<String> {
    let mut a = strs(&["-init_hw_device", "d3d11va", "-filter_complex"]);
    a.push(format!(
        "ddagrab=output_idx={}:framerate={}:draw_mouse=0",
        c.output, c.fps
    ));
    a
}

/// AMF encoder at constant QP, a keyframe every segment, no B-frames.
pub fn encoder_args(c: &Capture) -> Vec<String> {
    let codec = match c.codec {
        Codec::Hevc => "hevc_amf",
        Codec::Av1 => "av1_amf",
    };
    let mut a = strs(&["-c:v", codec, "-quality", "speed", "-rc", "cqp"]);
    a.extend([
        "-qp_i".into(), c.qp_i.to_string(),
        "-qp_p".into(), c.qp_p.to_string(),
        "-g".into(), (c.fps * SEGMENT_SECS).to_string(),
        "-bf".into(), "0".into(),
    ]);
    a
}

/// Wrapping MPEG-TS segments plus a bounded CSV index, both in `buffer_dir`.
pub fn segment_args(c: &Capture) -> Vec<String> {
    let n = segment_count(c.buffer_secs).to_string();
    let index = c.buffer_dir.join(INDEX_FILE).to_string_lossy().into_owned();
    let pattern = c.buffer_dir.join(SEGMENT_PATTERN).to_string_lossy().into_owned();
    let mut a = strs(&["-f", "segment", "-segment_time"]);
    a.push(SEGMENT_SECS.to_string());
    a.extend(["-segment_wrap".into(), n.clone(), "-segment_list_size".into(), n]);
    a.extend(strs(&["-segment_format", "mpegts", "-reset_timestamps", "1", "-segment_list"]));
    a.extend([index, "-segment_list_type".into(), "csv".into(), pattern]);
    a
}

/// The full ring-buffer command line (after the exe name).
pub fn capture_args(c: &Capture) -> Vec<String> {
    let mut a = strs(&["-hide_banner", "-loglevel", "warning", "-stats", "-stats_period", "1"]);
    a.extend(input_args(c));
    a.extend(encoder_args(c));
    a.extend(segment_args(c));
    a
}
```

```rust
//! ffmpeg `-stats` lines and the "encoder falling behind" rule.

use crate::Ms;

/// One progress report.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Stats {
    pub frame: u64,
    pub fps: f32,
    pub speed: f32,
}

/// The value after `key=` where `key` starts a whitespace-separated token; ffmpeg pads
/// values with spaces (`fps= 51`), so leading spaces are skipped.
fn field<'a>(line: &'a str, key: &str) -> Option<&'a str> {
    let pat = format!("{key}=");
    let mut from = 0;
    while let Some(i) = line[from..].find(&pat) {
        let at = from + i;
        if at == 0 || line[..at].ends_with(char::is_whitespace) {
            let rest = line[at + pat.len()..].trim_start();
            return rest.split_whitespace().next();
        }
        from = at + pat.len();
    }
    None
}

/// Parses `frame= 103 fps= 51 … speed=0.848x`. `None` for any other line, or while ffmpeg
/// still reports `speed=N/A`.
pub fn parse_stats(line: &str) -> Option<Stats> {
    Some(Stats {
        frame: field(line, "frame")?.parse().ok()?,
        fps: field(line, "fps")?.parse().ok()?,
        speed: field(line, "speed")?.strip_suffix('x')?.parse().ok()?,
    })
}

/// Below this `speed` the encoder can't keep up with real time.
pub const BEHIND_SPEED: f32 = 0.98;
/// How long `speed` must stay below [`BEHIND_SPEED`] before it counts.
pub const BEHIND_FOR: Ms = 10_000;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SpeedEvent {
    FallingBehind,
    Recovered,
}

/// Turns a stream of `speed` samples into one event when the encoder starts falling behind
/// and one when it recovers.
#[derive(Debug, Clone, Default)]
pub struct SpeedMonitor {
    slow_since: Option<Ms>,
    behind: bool,
}

impl SpeedMonitor {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn behind(&self) -> bool {
        self.behind
    }

    /// Forget everything, e.g. when ffmpeg restarts.
    pub fn reset(&mut self) {
        *self = Self::default();
    }

    pub fn observe(&mut self, now: Ms, speed: f32) -> Option<SpeedEvent> {
        if speed < BEHIND_SPEED {
            let since = *self.slow_since.get_or_insert(now);
            if !self.behind && now.saturating_sub(since) >= BEHIND_FOR {
                self.behind = true;
                return Some(SpeedEvent::FallingBehind);
            }
            None
        } else {
            self.slow_since = None;
            if self.behind {
                self.behind = false;
                return Some(SpeedEvent::Recovered);
            }
            None
        }
    }
}
```

```rust
//! When to start, stop and restart ffmpeg, as a state machine over game presence and ffmpeg
//! exits. Time is passed in, so every transition is deterministic.
//!
//! `Idle → Starting` (game seen) `→ Recording` (still there after 5 s) `→ Stopping` (game gone)
//! `→ Idle` (still gone after 5 s). ffmpeg crashes while recording are retried with backoff;
//! the sixth crash within 10 minutes goes to `Failed` until the game is next launched.

use crate::Ms;

pub const START_DEBOUNCE: Ms = 5_000;
pub const STOP_DEBOUNCE: Ms = 5_000;
/// Delay before the 1st, 2nd and every later restart.
pub const BACKOFF: [Ms; 3] = [1_000, 2_000, 5_000];
/// Restarts allowed within [`RESTART_WINDOW`]; the next crash gives up.
pub const MAX_RESTARTS: usize = 5;
pub const RESTART_WINDOW: Ms = 10 * 60 * 1_000;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Phase {
    Idle,
    Starting,
    Recording,
    Stopping,
    Failed,
}

/// What the caller must do after a transition.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Command {
    /// A session begins: empty the buffer folder, then start ffmpeg.
    StartSession,
    /// ffmpeg died mid-session: start it again, keeping the buffer.
    Respawn,
    /// The session is over: stop ffmpeg gracefully.
    StopSession,
    /// Too many crashes: ffmpeg stays stopped until the next game launch.
    GiveUp,
}

#[derive(Debug, Clone)]
pub struct Watcher {
    phase: Phase,
    /// When the current phase began (debounce timers).
    since: Ms,
    respawn_at: Option<Ms>,
    /// When each restart in the current window was scheduled.
    restarts: Vec<Ms>,
}

impl Default for Watcher {
    fn default() -> Self {
        Self::new()
    }
}

impl Watcher {
    pub fn new() -> Self {
        Watcher { phase: Phase::Idle, since: 0, respawn_at: None, restarts: Vec::new() }
    }

    pub fn phase(&self) -> Phase {
        self.phase
    }

    fn enter(&mut self, phase: Phase, now: Ms) {
        self.phase = phase;
        self.since = now;
    }

    /// Feed the latest process snapshot.
    pub fn on_game(&mut self, now: Ms, running: bool) -> Option<Command> {
        let waited = now.saturating_sub(self.since);
        match (self.phase, running) {
            (Phase::Idle, true) => self.enter(Phase::Starting, now),
            (Phase::Starting, false) => self.enter(Phase::Idle, now),
            (Phase::Starting, true) if waited >= START_DEBOUNCE => {
                self.enter(Phase::Recording, now);
                self.restarts.clear();
                self.respawn_at = None;
                return Some(Command::StartSession);
            }
            (Phase::Recording, false) => self.enter(Phase::Stopping, now),
            (Phase::Stopping, true) => self.enter(Phase::Recording, now),
            (Phase::Stopping, false) if waited >= STOP_DEBOUNCE => {
                self.enter(Phase::Idle, now);
                self.respawn_at = None;
                return Some(Command::StopSession);
            }
            (Phase::Failed, false) => self.enter(Phase::Idle, now),
            _ => {}
        }
        None
    }

    /// ffmpeg exited without being asked to, or could not be started.
    pub fn on_ffmpeg_exit(&mut self, now: Ms) -> Option<Command> {
        if !matches!(self.phase, Phase::Recording | Phase::Stopping) {
            return None;
        }
        self.restarts.retain(|&t| now.saturating_sub(t) < RESTART_WINDOW);
        if self.restarts.len() >= MAX_RESTARTS {
            self.enter(Phase::Failed, now);
            self.respawn_at = None;
            return Some(Command::GiveUp);
        }
        let delay = BACKOFF[self.restarts.len().min(BACKOFF.len() - 1)];
        self.restarts.push(now);
        self.respawn_at = Some(now + delay);
        None
    }

    /// Call regularly; fires a due restart.
    pub fn on_tick(&mut self, now: Ms) -> Option<Command> {
        match self.respawn_at {
            Some(at) if self.phase == Phase::Recording && now >= at => {
                self.respawn_at = None;
                Some(Command::Respawn)
            }
            _ => None,
        }
    }
}

/// Whether any of `running` (exe file names) is one of `wanted`, ignoring ASCII case.
pub fn game_running<'a>(running: impl IntoIterator<Item = &'a str>, wanted: &[String]) -> bool {
    running
        .into_iter()
        .any(|r| wanted.iter().any(|w| w.eq_ignore_ascii_case(r)))
}

/// What the tray icon shows: grey, red, or yellow (for both warning and failed).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum TrayStatus {
    Idle,
    Recording,
    Warning,
    Failed,
}

pub fn tray_status(phase: Phase, warning: bool) -> TrayStatus {
    match phase {
        Phase::Failed => TrayStatus::Failed,
        _ if warning => TrayStatus::Warning,
        Phase::Recording | Phase::Stopping => TrayStatus::Recording,
        Phase::Idle | Phase::Starting => TrayStatus::Idle,
    }
}
```

```rust
//! Checking the monitor `capture.output` points at.

use std::fmt;

/// One DXGI output (monitor) on the primary GPU.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct OutputInfo {
    /// The `ddagrab` `output_idx`.
    pub index: u32,
    /// e.g. `\\.\DISPLAY1`.
    pub name: String,
    pub width: u32,
    pub height: u32,
    pub refresh_hz: u32,
    /// Windows HDR (BT.2020 PQ) is on.
    pub hdr: bool,
}

impl fmt::Display for OutputInfo {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        let range = if self.hdr { "HDR" } else { "SDR" };
        write!(f, "{}: {} {}x{} @ {} Hz {range}", self.index, self.name, self.width, self.height, self.refresh_hz)
    }
}

/// Finds monitor `output`. `Err` if it doesn't exist; otherwise the warnings about it.
pub fn check_output(outputs: &[OutputInfo], output: u32, fps: u32) -> Result<Vec<String>, String> {
    let Some(o) = outputs.iter().find(|o| o.index == output) else {
        if outputs.is_empty() {
            return Err(format!("capture.output = {output}: no monitors found on the primary GPU"));
        }
        let list: Vec<String> = outputs.iter().map(ToString::to_string).collect();
        return Err(format!("capture.output = {output}: no such monitor. Monitors: {}", list.join(", ")));
    };
    let mut warnings = Vec::new();
    if o.refresh_hz < fps {
        warnings.push(format!(
            "monitor {} ({}) runs at {} Hz, below capture.fps = {fps}: frames will repeat",
            o.index, o.name, o.refresh_hz
        ));
    }
    if o.hdr {
        warnings.push(format!(
            "monitor {} ({}) has Windows HDR on: colours will be off and files larger",
            o.index, o.name
        ));
    }
    Ok(warnings)
}
```

```rust
//! The monitors on the primary GPU, as `ddagrab` numbers them.

use anyhow::{Context, Result};
use retake_core::display::OutputInfo;
use windows::Win32::Graphics::Dxgi::Common::DXGI_COLOR_SPACE_RGB_FULL_G2084_NONE_P2020;
use windows::Win32::Graphics::Dxgi::{CreateDXGIFactory1, DXGI_ERROR_NOT_FOUND, IDXGIFactory1, IDXGIOutput6};
use windows::Win32::Graphics::Gdi::{DEVMODEW, ENUM_CURRENT_SETTINGS, EnumDisplaySettingsW};
use windows::core::{Interface, PCWSTR};

/// Every output of adapter 0 — the adapter `-init_hw_device d3d11va` uses by default.
pub fn outputs() -> Result<Vec<OutputInfo>> {
    // SAFETY: COM calls on interfaces we own; `mode` and `name` outlive the calls using them.
    unsafe {
        let factory: IDXGIFactory1 = CreateDXGIFactory1().context("CreateDXGIFactory1")?;
        let adapter = match factory.EnumAdapters1(0) {
            Ok(a) => a,
            Err(e) if e.code() == DXGI_ERROR_NOT_FOUND => return Ok(Vec::new()),
            Err(e) => return Err(e).context("EnumAdapters1"),
        };
        let mut list = Vec::new();
        for index in 0.. {
            let output = match adapter.EnumOutputs(index) {
                Ok(o) => o,
                Err(e) if e.code() == DXGI_ERROR_NOT_FOUND => break,
                Err(e) => return Err(e).context("EnumOutputs"),
            };
            let desc = output.cast::<IDXGIOutput6>().context("IDXGIOutput6")?.GetDesc1().context("GetDesc1")?;
            let end = desc.DeviceName.iter().position(|&c| c == 0).unwrap_or(desc.DeviceName.len());
            let name = String::from_utf16_lossy(&desc.DeviceName[..end]);
            let mut mode = DEVMODEW { dmSize: size_of::<DEVMODEW>() as u16, ..Default::default() };
            let ok = EnumDisplaySettingsW(PCWSTR(desc.DeviceName.as_ptr()), ENUM_CURRENT_SETTINGS, &mut mode).as_bool();
            let (width, height, refresh_hz) = if ok {
                (mode.dmPelsWidth, mode.dmPelsHeight, mode.dmDisplayFrequency)
            } else {
                let r = desc.DesktopCoordinates;
                ((r.right - r.left) as u32, (r.bottom - r.top) as u32, 0)
            };
            tracing::info!(index, name = %name, width, height, refresh_hz, color_space = desc.ColorSpace.0, "monitor");
            list.push(OutputInfo {
                index,
                name,
                width,
                height,
                refresh_hz,
                hdr: desc.ColorSpace == DXGI_COLOR_SPACE_RGB_FULL_G2084_NONE_P2020,
            });
        }
        Ok(list)
    }
}
```

```rust
//! The buffer folder: which files are Retake's, clearing them, its README, and which drives
//! may hold it.

use std::fs;
use std::io;
use std::path::Path;

use crate::ffmpeg_args::INDEX_FILE;

pub const README_NAME: &str = "README.txt";
pub const README_TEXT: &str = "\
This folder is Retake's scratch area for the rolling video buffer.

Everything here is overwritten while Siege runs and cleared when a new session starts,
so it is safe to delete. For speed, exclude this folder from Windows Defender real-time
scanning and keep it out of OneDrive or any other synced folder.
";

/// Below this, starting a session logs a warning.
pub const MIN_FREE_BYTES: u64 = 5 * 1024 * 1024 * 1024;

/// `seg_<digits>.ts` or `index.csv`, ignoring ASCII case.
pub fn is_buffer_file(name: &str) -> bool {
    let lower = name.to_ascii_lowercase();
    if lower == INDEX_FILE {
        return true;
    }
    lower
        .strip_prefix("seg_")
        .and_then(|r| r.strip_suffix(".ts"))
        .is_some_and(|d| !d.is_empty() && d.bytes().all(|b| b.is_ascii_digit()))
}

/// Deletes Retake's own files in `dir` (never folders or anything else). Returns how many.
pub fn clear_dir(dir: &Path) -> io::Result<usize> {
    let mut n = 0;
    for entry in fs::read_dir(dir)? {
        let entry = entry?;
        if entry.file_type()?.is_file() && entry.file_name().to_str().is_some_and(is_buffer_file) {
            fs::remove_file(entry.path())?;
            n += 1;
        }
    }
    Ok(n)
}

/// Writes the README unless one is already there.
pub fn write_readme(dir: &Path) -> io::Result<()> {
    let p = dir.join(README_NAME);
    if p.exists() {
        return Ok(());
    }
    fs::write(p, README_TEXT)
}

    CdRom,

/// Why `dir`'s drive can't hold the buffer, if it can't.
pub fn drive_problem(kind: DriveKind, dir: &Path) -> Option<String> {
    let why = match kind {
        DriveKind::Fixed | DriveKind::Ram => return None,
        DriveKind::Remote => "is on a network drive; use a local SSD",
        DriveKind::Removable => "is on a removable drive; use a local SSD",
        DriveKind::CdRom => "is on a CD/DVD drive; use a local SSD",
        DriveKind::Unknown => "is on a drive of unknown type; use a local SSD",
    };
    Some(format!("capture.buffer_dir = {}: {why}", dir.display()))
}

/// A warning when less than [`MIN_FREE_BYTES`] is free.
pub fn low_space_warning(free: u64, dir: &Path) -> Option<String> {
    (free < MIN_FREE_BYTES).then(|| {
        let gb = free as f64 / (1024.0 * 1024.0 * 1024.0);
        format!(
            "capture.buffer_dir = {}: only {:.1} GB free (5 GB recommended)",
            dir.display(),
            (gb * 10.0).floor() / 10.0
        )
    })
}
```

```rust
//! Drive type and free space for the buffer folder.

use std::path::Path;

use anyhow::{Context, Result};
use retake_core::buffer::DriveKind;
use windows::Win32::Storage::FileSystem::{GetDiskFreeSpaceExW, GetDriveTypeW, GetVolumePathNameW};
use windows::core::{HSTRING, PCWSTR};

// GetDriveTypeW return values (winbase.h).
const DRIVE_REMOVABLE: u32 = 2;
const DRIVE_FIXED: u32 = 3;
const DRIVE_REMOTE: u32 = 4;
const DRIVE_CDROM: u32 = 5;
const DRIVE_RAMDISK: u32 = 6;

/// The kind of drive `dir` (which must exist) is on.
pub fn drive_kind(dir: &Path) -> DriveKind {
    let mut root = [0u16; 261];
    // SAFETY: `root` is a writable buffer of the length passed; strings outlive the calls.
    let kind = unsafe {
        if GetVolumePathNameW(&HSTRING::from(dir.as_os_str()), &mut root).is_err() {
            return DriveKind::Unknown;
        }
        GetDriveTypeW(PCWSTR(root.as_ptr()))
    };
    match kind {
        DRIVE_FIXED => DriveKind::Fixed,
        DRIVE_RAMDISK => DriveKind::Ram,
        DRIVE_REMOVABLE => DriveKind::Removable,
        DRIVE_REMOTE => DriveKind::Remote,
        DRIVE_CDROM => DriveKind::CdRom,
        _ => DriveKind::Unknown,
    }
}

/// Bytes free to this user on `dir`'s drive.
pub fn free_bytes(dir: &Path) -> Result<u64> {
    let mut free = 0u64;
    // SAFETY: `free` is a valid u64 out-pointer; the path outlives the call.
    unsafe { GetDiskFreeSpaceExW(&HSTRING::from(dir.as_os_str()), Some(&mut free), None, None) }
        .with_context(|| format!("GetDiskFreeSpaceExW({})", dir.display()))?;
    Ok(free)
}
```

```rust
//! Which processes are running, from a Toolhelp snapshot. This never opens a process — the
//! anti-cheat rules forbid touching Siege's — it only reads the system's process list.

use anyhow::{Context, Result};
use windows::Win32::Foundation::CloseHandle;
use windows::Win32::System::Diagnostics::ToolHelp::{
    CreateToolhelp32Snapshot, PROCESSENTRY32W, Process32FirstW, Process32NextW, TH32CS_SNAPPROCESS,
};

/// Exe file names (e.g. `RainbowSix.exe`) of every running process.
pub fn process_names() -> Result<Vec<String>> {
    // SAFETY: the snapshot handle is closed below; `entry` is a properly sized out-struct.
    unsafe {
        let snap = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0).context("CreateToolhelp32Snapshot")?;
        let mut entry = PROCESSENTRY32W { dwSize: size_of::<PROCESSENTRY32W>() as u32, ..Default::default() };
        let mut names = Vec::new();
        let mut more = Process32FirstW(snap, &mut entry).is_ok();
        while more {
            let end = entry.szExeFile.iter().position(|&c| c == 0).unwrap_or(entry.szExeFile.len());
            names.push(String::from_utf16_lossy(&entry.szExeFile[..end]));
            more = Process32NextW(snap, &mut entry).is_ok();
        }
        let _ = CloseHandle(snap);
        Ok(names)
    }
}
```

```rust
//! A running ffmpeg: spawned through the job, its stats parsed, stopped gracefully.

use std::io::Write;
use std::os::windows::io::AsRawHandle;
use std::path::{Path, PathBuf};
use std::process::{Child, ChildStdin, ExitStatus};
use std::time::{Duration, Instant};

use anyhow::Result;
use retake_core::progress::{Stats, parse_stats};
use windows::Win32::Foundation::HANDLE;
use windows::Win32::System::ProcessStatus::{GetProcessMemoryInfo, PROCESS_MEMORY_COUNTERS};

use crate::child::ChildJob;

/// How long ffmpeg gets to finish after `q` before it is terminated.
pub const GRACE: Duration = Duration::from_secs(3);

pub struct Ffmpeg {
    child: Child,
    stdin: Option<ChildStdin>,
}

impl Ffmpeg {
    /// Starts `exe args…`. Stats lines go to `on_stats`; every other stderr line is logged at
    /// `warn` (ffmpeg runs with `-loglevel warning`, so they are all warnings or errors).
    pub fn spawn(job: &ChildJob, exe: &Path, args: &[String], on_stats: impl Fn(Stats) + Send + 'static) -> Result<Ffmpeg> {
        let mut child = job.spawn_supervised(exe, args, move |line| match parse_stats(line) {
            Some(s) => on_stats(s),
            None => tracing::warn!(target: "ffmpeg", "{line}"),
        })?;
        let stdin = child.stdin.take();
        Ok(Ffmpeg { child, stdin })
    }

    pub fn pid(&self) -> u32 {
        self.child.id()
    }

    /// The exit status, if it has exited.
    pub fn exited(&mut self) -> Option<ExitStatus> {
        self.child.try_wait().ok().flatten()
    }

    /// Writes `q`, waits up to `grace` for a clean exit, then terminates it.
    pub fn stop(mut self, grace: Duration) {
        if let Some(mut stdin) = self.stdin.take() {
            let _ = stdin.write_all(b"q").and_then(|()| stdin.flush());
        }
        let start = Instant::now();
        while start.elapsed() < grace {
            if let Some(status) = self.exited() {
                tracing::info!(pid = self.pid(), %status, "ffmpeg stopped");
                return;
            }
            std::thread::sleep(Duration::from_millis(50));
        }
        tracing::warn!(pid = self.pid(), "ffmpeg ignored q for {grace:?}; terminating");
        let _ = self.child.kill();
        let _ = self.child.wait();
    }

    /// Current working set in bytes.
    pub fn working_set(&self) -> Option<u64> {
        let mut c = PROCESS_MEMORY_COUNTERS { cb: size_of::<PROCESS_MEMORY_COUNTERS>() as u32, ..Default::default() };
        // SAFETY: our own child's handle, valid while `self.child` lives; `c` is sized correctly.
        unsafe { GetProcessMemoryInfo(HANDLE(self.child.as_raw_handle()), &mut c, c.cb) }.ok()?;
        Some(c.WorkingSetSize as u64)
    }
}
```

```rust
    fn new(s: Setup, stats_tx: Sender<Event>) -> Loop {
        let args = capture_args(&s.capture);
        tracing::info!(args = %args.join(" "), "ffmpeg command");
        Loop { s, stats_tx, args, epoch: Instant::now(), watcher: Watcher::new(), speed: SpeedMonitor::new(), ffmpeg: None, last_stats: None, shown: None }
    }

    fn now(&self) -> Ms {
        self.epoch.elapsed().as_millis() as Ms
    }

    fn run(mut self, rx: Receiver<Event>) {
        let mut next_poll: Ms = 0;
        let mut next_summary: Ms = SUMMARY_EVERY;
        self.publish();
        loop {
            match rx.recv_timeout(TICK) {
                Ok(Event::Stats(st)) => self.on_stats(st),
                Ok(Event::Shutdown) | Err(RecvTimeoutError::Disconnected) => break,
                Err(RecvTimeoutError::Timeout) => {}
            }
            let now = self.now();
            if now >= next_poll {
                next_poll = now + POLL;
                match process_names() {
                    Ok(names) => {
                        let running = game_running(names.iter().map(String::as_str), &self.s.processes);
                        let cmd = self.watcher.on_game(now, running);
                        self.apply(cmd, now);
                    }
                    Err(e) => tracing::warn!("process snapshot failed: {e:#}"),
                }
            }
            if let Some(status) = self.ffmpeg.as_mut().and_then(Ffmpeg::exited) {
                tracing::warn!(%status, "ffmpeg exited unexpectedly");
                self.ffmpeg = None;
                self.speed.reset();
                let cmd = self.watcher.on_ffmpeg_exit(now);
                self.apply(cmd, now);
            }
            let cmd = self.watcher.on_tick(now);
            self.apply(cmd, now);
            if now >= next_summary {
                next_summary = now + SUMMARY_EVERY;
                self.log_summary();
            }
            self.publish();
        }
        if let Some(f) = self.ffmpeg.take() {
            f.stop(GRACE);
        }
    }

    fn on_stats(&mut self, st: Stats) {
        self.last_stats = Some(st);
        match self.speed.observe(self.now(), st.speed) {
            Some(SpeedEvent::FallingBehind) => tracing::warn!(speed = st.speed, fps = st.fps, "encoder falling behind"),
            Some(SpeedEvent::Recovered) => tracing::info!(speed = st.speed, "encoder caught up"),
            None => {}
        }
    }

    /// Carries out `cmd`; a failed spawn feeds back into the state machine as an exit.
    fn apply(&mut self, mut cmd: Option<Command>, now: Ms) {
        while let Some(c) = cmd.take() {
            match c {
                Command::StartSession => {
                    tracing::info!("game running; starting recording");
                    let dir = &self.s.capture.buffer_dir;
                    match clear_dir(dir) {
                        Ok(n) => tracing::info!(deleted = n, "buffer cleared"),
                        Err(e) => tracing::warn!("clearing {}: {e}", dir.display()),
                    }
                    match free_bytes(dir) {
                        Ok(free) => if let Some(w) = low_space_warning(free, dir) { tracing::warn!("{w}") },
                        Err(e) => tracing::warn!("{e:#}"),
                    }
                    cmd = self.spawn(now);
                }
                Command::Respawn => {
                    tracing::info!("restarting ffmpeg");
                    cmd = self.spawn(now);
                }
                Command::StopSession => {
                    tracing::info!("game closed; stopping recording");
                    if let Some(f) = self.ffmpeg.take() {
                        f.stop(GRACE);
                    }
                    self.speed.reset();
                }
                Command::GiveUp => tracing::error!(
                    "ffmpeg crashed too often (5 restarts in 10 minutes); not retrying until the game is next launched"
                ),
            }
        }
    }

    fn spawn(&mut self, now: Ms) -> Option<Command> {
        let tx = self.stats_tx.clone();
        match Ffmpeg::spawn(&self.s.job, &self.s.ffmpeg, &self.args, move |st| { let _ = tx.send(Event::Stats(st)); }) {
            Ok(f) => {
                tracing::info!(pid = f.pid(), "ffmpeg recording");
                self.ffmpeg = Some(f);
                None
            }
            Err(e) => {
                tracing::error!("starting ffmpeg: {e:#}");
                self.watcher.on_ffmpeg_exit(now)
            }
        }
    }

    fn log_summary(&self) {
        if let (Some(f), Some(st)) = (&self.ffmpeg, self.last_stats) {
            let mb = f.working_set().map_or(0, |b| b / (1024 * 1024));
            tracing::info!(fps = st.fps, speed = st.speed, frame = st.frame, ffmpeg_mb = mb, "recording");
        }
    }

    fn publish(&mut self) {
        let s = tray_status(self.watcher.phase(), self.s.warning || self.speed.behind());
        if self.shown != Some(s) {
            tracing::info!(phase = ?self.watcher.phase(), status = ?s, "status");
            (self.s.notify)(s);
            self.shown = Some(s);
        }
    }
}
```
