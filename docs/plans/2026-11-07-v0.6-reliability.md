# v0.6 A/V sync & reliability Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [ ]` for tracking.

**Goal:** Retake runs a whole evening unattended: audio stays in sync for hours, every failure in the matrix recovers or fails visibly, and nothing leaks.
**Architecture:** sync measurement moves into Retake as `retake sync-check` (pure pairing logic in `retake-core::sync`, ffmpeg extraction in the binary). Failures are handled where they happen: the audio pump restarts a dead or stale capture, the recorder watches free space and power events, the saver reports failures to the tray. A `--diag` flag logs memory and handle counts for soaks.
**Tech stack:** as v0.5.

## Global Constraints

- No forbidden APIs; no process handles on the game.
- Logic in `retake-core` with unit tests; Windows glue thin.
- Never fill the disk: recording stops below 2 GB free and resumes above 3 GB.
- A failure the user must know about turns the tray icon yellow (warning) or red-cross (failed) **and** logs one clear line.

### Task 1: `retake-core::sync` and `retake sync-check`

**Files:** Create `crates/retake-core/src/sync.rs`, `crates/retake/src/sync_check.rs`; modify `main.rs` (subcommand before single-instance), `lib.rs`.

**Interfaces:**
- `pub fn rising_edges(samples: &[(f64, f64)], high: f64, low: f64) -> Vec<f64>` — times where a brightness series crosses from below `low` to above `high`.
- `pub fn onsets(samples: &[i16], rate: u32, start: f64, loud: i16, quiet_secs: f64) -> Vec<f64>` — first loud sample after `quiet_secs` of quiet.
- `pub fn pair(flashes: &[f64], sounds: &[f64], max_gap: f64) -> Vec<f64>` — offsets (sound − flash) in ms for each flash with a sound within `max_gap`.
- `pub struct SyncReport { pub pairs: usize, pub median_ms: f64, pub worst_ms: f64 }`, `pub fn report(offsets: &[f64]) -> Option<SyncReport>`.
- CLI: `retake.exe sync-check <clip> [--crop w:h:x:y] [--track N]`; default crop = centre 20 % of the frame; prints every pair and the median; exit 0 when |median| ≤ 8 ms and all pairs ≤ 50 ms, else 1.

- [ ] Tests for each function (edges with noise, onsets after silence, pairing, median of even/odd). Fail → implement → pass. Replace `examples/avsync_check.rs` with the subcommand. Commit.

### Task 2: Capture recovery in the audio pump

**Files:** modify `crates/retake/src/audio_pump.rs`, `crates/retake-audio/src/wasapi.rs`.

**Interfaces:**
- `retake_audio::default_device_id(render: bool) -> Option<String>`.
- Pump: every 2 s, if the capture thread has finished (device unplugged, invalidated) or, for `DeviceLoopback` and the default mic, the default device id changed, drop it and start a new one; the track keeps carrying silence meanwhile. A lost mic or output sets a shared warning flag (cleared when it is back), logged once per change.
- `Pump::warning(&self) -> bool`.

- [ ] Unplug test by hand is impossible here; test with a fake: `Capture::start` on a mic name that doesn't exist fails, the pump retries and logs once. Commit.

### Task 3: Disk space, power events, saver errors, display changes

**Files:** modify `recorder.rs`, `tray.rs`, `saver.rs`, `retake-core/src/watcher.rs` (pure free-space hysteresis).

- `retake_core::watcher::DiskGuard` — `on_free(bytes) -> Option<DiskEvent>` with `Low` below 2 GB and `Ok` above 3 GB (hysteresis), unit-tested.
- Recorder checks free space on the buffer drive every poll (2 s); `Low` stops the session and shows Failed with "disk almost full"; `Ok` lets the watcher start again.
- Tray window handles `WM_POWERBROADCAST`: `PBT_APMSUSPEND` → recorder stops ffmpeg; `PBT_APMRESUMEAUTOMATIC` → recorder restarts if the game still runs (new `Event::Suspend` / `Event::Resume`).
- Saver: a failed save shows a tray error toast with the reason; the buffer keeps running (already true; add the toast).
- Display change: ddagrab errors make ffmpeg exit; the existing respawn backoff (1/2/5 s) covers it. Check by changing the secondary monitor's refresh rate.

- [ ] Unit tests for `DiskGuard`; hand tests listed in Task 5. Commit.

### Task 4: Resource hygiene and `--diag`
