# Retake v0.3 — Manual Clip Save Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [x]` for tracking.

**Goal:** Pressing `F9` in-game saves the last `pre_roll` seconds plus `post_roll` seconds after the press as one `.mkv` in `clips/raw/`; `Ctrl+F9` saves the whole buffer. Saving is a stream copy: no re-encode, no GPU.

**Architecture:** Pure logic in `retake-core`: hotkey-string parsing, `index.csv` parsing and segment selection (wrap, gaps, the segment being overwritten), a clip scheduler that merges presses inside a pending post-roll, file naming, the concat list and the concat ffmpeg arguments, and a generated WAV tone. The `retake` binary adds `RegisterHotKey` on the tray's hidden window, a saver thread that runs one clip job at a time (wait for the last segment to close → copy segments to `clips/tmp/<id>/` → re-check the index → concat at below-normal priority into `<name>.mkv.part` → rename), `PlaySoundW` cues, and an "Open last clip" tray item. The recorder publishes the current ffmpeg run (wall-clock start, run number) to a shared slot the saver reads.

**Tech stack:** Rust stable (MSVC), crates already in `Cargo.lock`; `windows` 0.62 gains `Win32_UI_Input_KeyboardAndMouse` (`RegisterHotKey`), `Win32_Media_Audio` (`PlaySoundW`), `Win32_System_SystemInformation` (`GetLocalTime`). Pinned ffmpeg 7.1.1 gyan full (`third_party/ffmpeg/bin/{ffmpeg,ffprobe}.exe`).

Source of requirements: roadmap doc *Retake — Roadmap v0.0 → v1.0*, tab **v0.3 Manual clip save**; anti-cheat rules (v0.8 tab) apply.

## Global Constraints

- Everything in the v0.1 and v0.2 plans' Global Constraints still holds: `retake-core` has no `windows` dependency; CI runs `cargo fmt --all --check`, `scripts/forbidden-apis.ps1`, `cargo clippy --all-targets -- -D warnings`, `cargo test --all`, `cargo build --release`; config errors read `<section>.<field> = <value>: <reason>`.
- Hotkeys: `RegisterHotKey` only, with `MOD_NOREPEAT`. **Never** a keyboard hook, `SetWindowsHookEx`, `GetAsyncKeyState` polling or raw-input fallback (anti-cheat rule 5). If a key is taken: log it, warn in the tray, carry on.
- No toasts or popups while recording (rule 6). Feedback = sound cue + tray only.
- Segments: `seg_NN.ts`, 2 s each (`SEGMENT_SECS`), `segment_count(buffer_secs)` slots; `index.csv` lines are `seg_03.ts,16.000000,18.000000` with times in seconds from the start of that ffmpeg run, already bounded to the slot count, written in time order (wrap shows as `seg_29` then `seg_00`).
- Clip files: `clips.out_dir/raw/YYYY-MM-DD_HHMMSS.mkv` (local time of the first press), `_full` before `.mkv` for `Ctrl+F9`; written as `<name>.part` then renamed. Work folder `clips.out_dir/tmp/<job id>/`, removed after each job and emptied at startup.
- Concat command: `ffmpeg -hide_banner -loglevel warning -nostdin -y -f concat -safe 0 -i <list> -c copy -map 0 -f matroska <out.part>`, child of the job object, `BELOW_NORMAL_PRIORITY_CLASS`, no window.
- Reading ring files: `std::fs::File::open` (shares read/write/delete) only. Never `std::fs::copy`.
- Defaults: `pre_roll = 15`, `post_roll = 3`, `hotkey = "F9"`, `hotkey_full = "Ctrl+F9"`, `sound_cue = true` (already in `default-config.toml`).
- Workspace version becomes `0.3.0`.

## Decisions made while planning (flagged)

1. **Checked with the pinned ffmpeg** (testsrc + libx264, wrap 5, 26 s): `index.csv` held `seg_03…seg_04, seg_00…seg_02` with absolute times 16–26 s; `-f concat -c copy -map 0` of those into a `.part` file needs `-f matroska` (no extension to infer from) and gave exactly 10.0 s.
2. **Wall clock = session start + index time.** The session start is `SystemTime::now()` taken just before ffmpeg is spawned (spec). ffmpeg's startup latency (~0.3–1 s) makes every segment appear that much earlier than it really was, so clips land up to ~1 s late. Within the 2 s rounding; the manual "shoot a wall" test is the check. Anchoring on the index file's mtime would be tighter; not done unless that test fails.
3. **`select` takes a window, not `pre`/`post`.** Spec: `select(segments, press_time, pre, post)`. Merged clips cover `[first press − pre, last press + post]`, so the function is `select(segs, press, from, to, writing)`. Same behaviour for a single press.
4. **"Currently being written" = the slot after the newest listed one.** The index only lists closed segments, but once the ring is full the next slot ffmpeg writes is the oldest listed entry, so that entry is dropped. After the game closes nothing is being written, and a full-buffer save loses that one oldest segment; acceptable.
5. **Overwrite safety is checked, not assumed.** After copying, the index is re-read; a copied segment counts only if it is still listed with the same times and is not the slot being written. Survivors go through `select` again so the clip stays contiguous around the press. With the defaults the oldest needed segment is ~40 s from being overwritten, so this matters mainly for `Ctrl+F9`.
6. **Clip merging is Normal-only.** An `F9` during a pending `F9` clip's post-roll (press time < pending end) moves the end to `press + post_roll`. `Ctrl+F9` never merges and never absorbs an `F9`; each is its own job. A press at exactly the pending end starts a new clip.
7. **A full clip covers `[press − buffer_secs, press + post_roll]`.**
8. **"About 3 s after the press" isn't reachable with `post_roll = 3`.** The clip can only be cut once the segment holding `press + 3 s` has closed (≤ 2 s later) and the concat has run (< 1 s), so expect ~4–6 s. The saver polls the index every 250 ms for a segment ending at or after the window end, and gives up waiting at `end + 2 × segment + 1 s` (e.g. the game closed) and saves what exists. Raise this with the user rather than chase it.
9. **Clip name collisions** (two clips in the same second, e.g. `post_roll = 0`) get `_2`, `_3`… before `.mkv`.
10. **Session slot is cleared before the buffer is.** On every ffmpeg spawn the recorder sets the slot to `None`, empties the buffer, spawns, then stores the new `Session`. A save that sees the run number change mid-copy fails with a log line instead of joining two runs.
11. **Hotkey strings are validated in `config::validate`**, so a bad `clips.hotkey` is a startup config error like any other, and `hotkey_full` must differ from `hotkey`.
12. **Tray warning for a taken hotkey**: icon goes yellow and the tooltip gains a second line `Hotkey F9 unavailable — another app may be using it` (both keys listed if both fail). Kept for the whole run; a `Failed` status still wins the tooltip's first line.
13. **Sound cues are generated in code** (16-bit mono 44.1 kHz sine with 5 ms fades): press = 880 Hz 70 ms, saved = 1320 Hz 110 ms. "Embedded WAV" without a binary asset in the repo.
14. **Pending clips are dropped on Quit**, with a log line. The recorder is stopping at the same time, so finishing them is not reliable.
15. **This laptop has no AMD GPU or Siege.** Here: unit tests, an opt-in (`--ignored`) end-to-end save using the real segmenter with `libx265` (HEVC like AMF), and a live check that `F9` registers, beeps and logs. Siege, mpv and Resolve checks are on the gaming PC (Task 9).
16. **Push/PR is outward-facing**: commits stay local on `feat/v0.3-clip-save`; push and PR only with the user's OK.
17. **Amended during execution: no audio on the laptop** (user, mid-Task 7). The `PlaySoundW` test is `#[ignore]` (opt-in), live runs here use `clips.sound_cue = false`, and the cues are heard only on the gaming PC (Task 9).
18. **Amended after code review** (`/code-review` of `main..HEAD`):
    - Startup cleanup removes only Retake's numbered work folders in `tmp/` and stale `*.mkv.part` in `raw/`, never a whole `tmp/` the user may own; a leftover that can't be removed is a warning, not fatal.
    - The saver drains every queued message before asking which clips are due, so presses that piled up during a save still merge.
    - Quitting sets a stop flag: the saver stops waiting for segments and starts no new saves (a copy/concat already running finishes).
    - `read_index` accepts a read only when two consecutive reads match, so a list caught mid-rewrite can't make intact segments look overwritten.
    - Replaces Decision 12's colour rule: a hotkey problem turns only the idle icon yellow; recording stays red, and the warning is always the tooltip's second line.
    - Merging stops once a clip would span more than `buffer_secs − 4 s` (`MERGE_MARGIN`); the next press starts a new clip.
    - Not changed: the spawn-time session anchor (Decision 2, spec-mandated, measured in Task 9); the hotkeys being parsed again in `main` (cheap, kept in one loop); the sub-second check-then-rename window in `raw/`.

```rust
//! Hotkey strings from `[clips]` (`F9`, `Ctrl+F9`, `Alt+Shift+K`) parsed into the modifier bits
//! and virtual-key code `RegisterHotKey` takes. Pure: the Win32 values are constants here.

pub const MOD_ALT: u32 = 0x1;
pub const MOD_CONTROL: u32 = 0x2;
pub const MOD_SHIFT: u32 = 0x4;
pub const MOD_WIN: u32 = 0x8;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Hotkey {
    pub modifiers: u32,
    pub vk: u32,
}

/// Parses `Mod+Mod+Key`, ignoring case and spaces around each part.
pub fn parse(s: &str) -> Result<Hotkey, String> {
    let parts: Vec<&str> = s.split('+').map(str::trim).collect();
    let (key, mods) = parts.split_last().expect("split yields at least one part");
    if mods.is_empty() && key.is_empty() {
        return Err("empty".into());
    }
    let mut modifiers = 0;
    for m in mods {
        let bit = modifier(m)
            .ok_or_else(|| format!("\"{m}\" is not a modifier (Ctrl, Alt, Shift, Win)"))?;
        if modifiers & bit != 0 {
            return Err(format!("\"{m}\" given twice"));
        }
        modifiers |= bit;
    }
    if key.is_empty() || modifier(key).is_some() {
        return Err("no key after the modifiers".into());
    }
    let vk = vk(key).ok_or_else(|| format!("unknown key \"{key}\""))?;
    Ok(Hotkey { modifiers, vk })
}

fn modifier(m: &str) -> Option<u32> {
    match m.to_ascii_lowercase().as_str() {
        "ctrl" | "control" => Some(MOD_CONTROL),
        "alt" => Some(MOD_ALT),
        "shift" => Some(MOD_SHIFT),
        "win" => Some(MOD_WIN),
        _ => None,
    }
}

fn vk(key: &str) -> Option<u32> {
    let k = key.to_ascii_lowercase();
    if let [c] = k.as_bytes()
        && c.is_ascii_alphanumeric()
    {
        return Some(u32::from(c.to_ascii_uppercase()));
    }
    let number = |prefix: &str| {
        k.strip_prefix(prefix)
            .filter(|d| !d.is_empty() && d.bytes().all(|b| b.is_ascii_digit()))
            .and_then(|d| d.parse::<u32>().ok())
    };
    if let Some(n) = number("f") {
        return (1..=24).contains(&n).then_some(0x6F + n);
    }
    if let Some(n) = number("numpad") {
        return (n <= 9).then_some(0x60 + n);
    }
    Some(match k.as_str() {
        "space" => 0x20,
        "pageup" => 0x21,
        "pagedown" => 0x22,
        "end" => 0x23,
        "home" => 0x24,
        "insert" => 0x2D,
        "delete" => 0x2E,
        "pause" => 0x13,
        _ => return None,
    })
}
```

```rust
//! The ring buffer's `index.csv` read as wall-clock segments, and the choice of which segments
//! make a clip. Pure; times are wall-clock milliseconds since the Unix epoch.

use crate::Ms;
use crate::ffmpeg_args::SEGMENT_SECS;

/// One closed segment of the ring, on the wall clock.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Segment {
    pub file: String,
    pub start: Ms,
    pub end: Ms,
}

pub const SEGMENT_MS: Ms = SEGMENT_SECS as Ms * 1000;
/// The largest gap between one segment's end and the next one's start that still counts as
/// contiguous.
pub const GAP_TOLERANCE: Ms = 500;

/// Parses ffmpeg's CSV segment list (`seg_03.ts,16.000000,18.000000` per line). Its times count
/// from the start of the ffmpeg run; adding `session_start` puts them on the wall clock. Lines
/// that don't parse, such as a half-written last line, are skipped. Sorted by start.
pub fn parse_index(text: &str, session_start: Ms) -> Vec<Segment> {
    let secs = |s: &str| {
        s.trim()
            .parse::<f64>()
            .ok()
            .filter(|v| v.is_finite() && *v >= 0.0)
            .map(|v| (v * 1000.0).round() as Ms)
    };
    let mut segs: Vec<Segment> = text
        .lines()
        .filter_map(|line| {
            let mut f = line.trim().split(',');
            let (file, start, end) = (f.next()?, f.next()?, f.next()?);
            if f.next().is_some() || file.is_empty() {
                return None;
            }
            let (start, end) = (secs(start)?, secs(end)?);
            (end > start).then(|| Segment {
                file: file.to_owned(),
                start: session_start + start,
                end: session_start + end,
            })
        })
        .collect();
    segs.sort_by_key(|s| s.start);
    segs
}

/// The ring slot of `seg_<n>.ts`.
pub fn slot(file: &str) -> Option<u32> {
    file.strip_prefix("seg_")?.strip_suffix(".ts")?.parse().ok()
}

/// The file ffmpeg is writing now: the slot after the newest listed segment. Once the ring is
/// full, that slot's listed entry is an old segment already being overwritten.
pub fn writing_file(segs: &[Segment], wrap: u32) -> Option<String> {
    let newest = slot(&segs.iter().max_by_key(|s| s.start)?.file)?;
    Some(format!("seg_{:02}.ts", (newest + 1) % wrap))
}

/// The segments for a clip covering `[from, to]` around `press`: every segment overlapping the
/// window except `writing`, in time order. If they don't run back to back (ffmpeg restarted
/// between them), only the contiguous run around `press` is kept: the one containing it, else
/// the last one starting before it, else the first.
pub fn select(segs: &[Segment], press: Ms, from: Ms, to: Ms, writing: Option<&str>) -> Vec<Segment> {
    let mut hit: Vec<&Segment> = segs
        .iter()
        .filter(|s| s.end > from && s.start < to && Some(s.file.as_str()) != writing)
        .collect();
    hit.sort_by_key(|s| s.start);
    let mut runs: Vec<Vec<Segment>> = Vec::new();
    for s in hit {
        match runs.last_mut() {
            Some(run) if s.start <= run[run.len() - 1].end + GAP_TOLERANCE => run.push(s.clone()),
            _ => runs.push(vec![s.clone()]),
        }
    }
    let span = |r: &Vec<Segment>| (r[0].start, r[r.len() - 1].end);
    let pick = runs
        .iter()
        .position(|r| {
            let (a, b) = span(r);
            a <= press && press < b
        })
        .or_else(|| runs.iter().rposition(|r| span(r).0 <= press))
        .unwrap_or(0);
    runs.into_iter().nth(pick).unwrap_or_default()
}

/// For each of `copied` (as listed before copying), whether it is certainly unchanged according
/// to `after`, the index re-read once copying finished: still listed with the same times and
/// not the file being written now. Anything else may have been overwritten mid-copy.
pub fn still_intact(copied: &[Segment], after: &[Segment], wrap: u32) -> Vec<bool> {
    let writing = writing_file(after, wrap);
    copied
        .iter()
        .map(|c| Some(&c.file) != writing.as_ref() && after.contains(c))
        .collect()
}
```

```rust
//! Hotkey presses turned into clip jobs: the window each clip covers, merging presses that land
//! in a pending clip's post-roll, and the file name and ffmpeg command for writing one. Pure.

use std::path::Path;

use crate::Ms;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Kind {
    /// `pre_roll` before the press to `post_roll` after it.
    Normal,
    /// The whole buffer up to `post_roll` after the press.
    Full,
}

/// Local date and time of a press, for the file name.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Stamp {
    pub year: u16,
    pub month: u8,
    pub day: u8,
    pub hour: u8,
    pub minute: u8,
    pub second: u8,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Press {
    /// Wall-clock ms since the Unix epoch.
    pub at: Ms,
    pub stamp: Stamp,
    pub kind: Kind,
}

/// One clip to write: wall-clock window `[from, to]`, named after its first press.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ClipJob {
    pub id: u64,
    pub kind: Kind,
    pub press: Ms,
    pub stamp: Stamp,
    pub from: Ms,
    pub to: Ms,
}

/// Pending clips, waiting out their post-roll.
pub struct Scheduler {
    pre: Ms,
    post: Ms,
    full_pre: Ms,
    next_id: u64,
    pending: Vec<ClipJob>,
}

impl Scheduler {
    /// `pre_roll` and `post_roll` from `[clips]` and `buffer_secs` from `[capture]`, in seconds.
    pub fn new(pre_roll: u32, post_roll: u32, buffer_secs: u32) -> Scheduler {
        let ms = |s: u32| Ms::from(s) * 1000;
        Scheduler {
            pre: ms(pre_roll),
            post: ms(post_roll),
            full_pre: ms(buffer_secs),
            next_id: 0,
            pending: Vec::new(),
        }
    }

    /// Records a press. A normal press inside a pending normal clip's post-roll moves that
    /// clip's end to `press + post_roll` and returns true; anything else starts a new clip.
    pub fn press(&mut self, p: Press) -> bool {
        if p.kind == Kind::Normal
            && let Some(job) = self
                .pending
                .iter_mut()
                .find(|j| j.kind == Kind::Normal && p.at < j.to)
        {
            job.to = job.to.max(p.at + self.post);
            return true;
        }
        let pre = match p.kind {
            Kind::Normal => self.pre,
            Kind::Full => self.full_pre,
        };
        self.pending.push(ClipJob {
            id: self.next_id,
            kind: p.kind,
            press: p.at,
            stamp: p.stamp,
            from: p.at.saturating_sub(pre),
            to: p.at + self.post,
        });
        self.next_id += 1;
        false
    }

    /// Removes and returns the clips whose post-roll is over at `now`, oldest first.
    pub fn due(&mut self, now: Ms) -> Vec<ClipJob> {
        let (due, wait): (Vec<_>, Vec<_>) = self.pending.drain(..).partition(|j| now >= j.to);
        self.pending = wait;
        due
    }

    pub fn pending(&self) -> usize {
        self.pending.len()
    }
}

/// `YYYY-MM-DD_HHMMSS.mkv`, with `_full` before the extension for a full-buffer clip.
pub fn clip_name(t: Stamp, kind: Kind) -> String {
    let suffix = match kind {
        Kind::Normal => "",
        Kind::Full => "_full",
    };
    format!(
        "{:04}-{:02}-{:02}_{:02}{:02}{:02}{suffix}.mkv",
        t.year, t.month, t.day, t.hour, t.minute, t.second
    )
}

/// `name` with `_<n>` before its extension, for a name that is already taken.
pub fn numbered(name: &str, n: u32) -> String {
    match name.rsplit_once('.') {
        Some((stem, ext)) => format!("{stem}_{n}.{ext}"),
        None => format!("{name}_{n}"),
    }
}

/// The concat demuxer's list for `files`, named relative to the list's own folder.
pub fn concat_list(files: &[String]) -> String {
    files
        .iter()
        .map(|f| format!("file '{}'\n", f.replace('\'', "'\\''")))
        .collect()
}

/// Joins the listed segments without re-encoding into Matroska at `out`. The format is given
/// explicitly because `out` ends in `.part`.
pub fn concat_args(list: &Path, out: &Path) -> Vec<String> {
    let mut a: Vec<String> = [
        "-hide_banner", "-loglevel", "warning", "-nostdin", "-y", "-f", "concat", "-safe", "0",
        "-i",
    ]
    .map(String::from)
    .to_vec();
    a.push(list.to_string_lossy().into_owned());
    a.extend(["-c", "copy", "-map", "0", "-f", "matroska"].map(String::from));
    a.push(out.to_string_lossy().into_owned());
    a
}
```

```rust
//! The short tones played when a clip hotkey is pressed and when the clip is written, built as
//! in-memory WAV files so no audio asset ships with Retake.

pub struct Tone {
    pub hz: u32,
    pub ms: u32,
}

pub const PRESS_CUE: Tone = Tone { hz: 880, ms: 70 };
pub const SAVED_CUE: Tone = Tone { hz: 1320, ms: 110 };

const RATE: u32 = 44_100;
const FADE_MS: u32 = 5;
const AMPLITUDE: f32 = 12_000.0;

/// A complete 16-bit mono 44.1 kHz WAV file of a sine at `t.hz` lasting `t.ms`, with 5 ms
/// fades so it doesn't click.
pub fn tone_wav(t: Tone) -> Vec<u8> {
    let n = RATE * t.ms / 1000;
    let fade = (RATE * FADE_MS / 1000).max(1);
    let data_len = n * 2;
    let mut w = Vec::with_capacity(44 + data_len as usize);
    w.extend_from_slice(b"RIFF");
    w.extend_from_slice(&(36 + data_len).to_le_bytes());
    w.extend_from_slice(b"WAVEfmt ");
    w.extend_from_slice(&16u32.to_le_bytes()); // fmt chunk size
    w.extend_from_slice(&1u16.to_le_bytes()); // PCM
    w.extend_from_slice(&1u16.to_le_bytes()); // mono
    w.extend_from_slice(&RATE.to_le_bytes());
    w.extend_from_slice(&(RATE * 2).to_le_bytes()); // byte rate
    w.extend_from_slice(&2u16.to_le_bytes()); // block align
    w.extend_from_slice(&16u16.to_le_bytes()); // bits per sample
    w.extend_from_slice(b"data");
    w.extend_from_slice(&data_len.to_le_bytes());
    for i in 0..n {
        let env = (i.min(n - 1 - i) as f32 / fade as f32).min(1.0);
        let phase = 2.0 * std::f32::consts::PI * t.hz as f32 * i as f32 / RATE as f32;
        let v = (phase.sin() * AMPLITUDE * env) as i16;
        w.extend_from_slice(&v.to_le_bytes());
    }
    w
}
```

```rust
//! Saving clips: copy the chosen segments out of the ring, check none was overwritten while
//! copying, join them with ffmpeg (stream copy) and publish the file under its final name.

use std::fs::{self, File};
use std::io;
use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex};
use std::time::Duration;

use anyhow::{Context, Result, bail};
use retake_core::Ms;
use retake_core::clip::{ClipJob, Kind, clip_name, concat_args, concat_list, numbered};
use retake_core::ffmpeg_args::INDEX_FILE;
use retake_core::segments::{Segment, parse_index, select, still_intact, writing_file};

use crate::child::ChildJob;

/// The ffmpeg run whose segments are in the buffer now.
#[derive(Debug, Clone)]
pub struct Session {
    /// The recorder's run counter; changes whenever ffmpeg is restarted and the buffer emptied.
    pub run: u64,
    /// Wall-clock ms when this ffmpeg run was spawned: `index.csv` time 0.
    pub start: Ms,
    pub buffer_dir: PathBuf,
    /// Number of ring slots.
    pub wrap: u32,
}

/// Written by the recorder, read by the saver. `None` while no run's segments are usable.
pub type SessionSlot = Arc<Mutex<Option<Session>>>;

pub fn current(slot: &SessionSlot) -> Option<Session> {
    slot.lock().unwrap_or_else(|e| e.into_inner()).clone()
}

/// `raw/` holds finished clips; `tmp/` holds one work folder per running save.
#[derive(Debug, Clone)]
pub struct ClipDirs {
    pub raw: PathBuf,
    pub tmp: PathBuf,
}

impl ClipDirs {
    pub fn new(out_dir: &Path) -> ClipDirs {
        ClipDirs {
            raw: out_dir.join("raw"),
            tmp: out_dir.join("tmp"),
        }
    }

    /// Creates both folders and deletes whatever an earlier run left in `tmp/`.
    pub fn prepare(&self) -> io::Result<()> {
        fs::create_dir_all(&self.raw)?;
        if self.tmp.exists() {
            fs::remove_dir_all(&self.tmp)?;
        }
        fs::create_dir_all(&self.tmp)
    }
}

/// Reads and parses `index.csv`, retrying briefly when it is caught mid-rewrite.
pub fn read_index(dir: &Path, start: Ms) -> Vec<Segment> {
    for _ in 0..5 {
        if let Ok(text) = fs::read_to_string(dir.join(INDEX_FILE)) {
            let segs = parse_index(&text, start);
            if !segs.is_empty() {
                return segs;
            }
        }
        std::thread::sleep(Duration::from_millis(50));
    }
    Vec::new()
}

/// Copies with `File::open`, which shares read, write and delete access, so ffmpeg can keep
/// rewriting the ring and replacing the index while we read. Don't use `fs::copy` here.
fn copy_shared(src: &Path, dst: &Path) -> io::Result<u64> {
    let mut from = File::open(src)?;
    let mut to = File::create(dst)?;
    io::copy(&mut from, &mut to)
}

/// Removes its folder when dropped, however the save ends.
struct WorkDir(PathBuf);

impl Drop for WorkDir {
    fn drop(&mut self) {
        if let Err(e) = fs::remove_dir_all(&self.0) {
            tracing::warn!(dir = %self.0.display(), "removing clip work folder: {e}");
        }
    }
}

/// Writes `job` as an `.mkv` in `dirs.raw` and returns its path. `concat(list, out)` joins the
/// listed files into `out` (ffmpeg in the app, a stand-in in tests).
pub fn save(
    job: &ClipJob,
    slot: &SessionSlot,
    dirs: &ClipDirs,
    concat: &dyn Fn(&Path, &Path) -> Result<()>,
) -> Result<PathBuf> {
    let s = current(slot).context("not recording; no clip saved")?;
    let listed = read_index(&s.buffer_dir, s.start);
    let writing = writing_file(&listed, s.wrap);
    let picked = select(&listed, job.press, job.from, job.to, writing.as_deref());
    if picked.is_empty() {
        bail!("no buffered video covers the press");
    }

    let work = WorkDir(dirs.tmp.join(job.id.to_string()));
    fs::create_dir_all(&work.0).with_context(|| format!("creating {}", work.0.display()))?;
    let names: Vec<String> = (0..picked.len()).map(|i| format!("{i:03}.ts")).collect();
    for (seg, name) in picked.iter().zip(&names) {
        copy_shared(&s.buffer_dir.join(&seg.file), &work.0.join(name))
            .with_context(|| format!("copying {}", seg.file))?;
    }

    if current(slot).map(|x| x.run) != Some(s.run) {
        bail!("recording restarted during the save");
    }
    let after = read_index(&s.buffer_dir, s.start);
    let ok = still_intact(&picked, &after, s.wrap);
    let intact: Vec<Segment> = picked
        .iter()
        .zip(&ok)
        .filter(|(_, ok)| **ok)
        .map(|(seg, _)| seg.clone())
        .collect();
    let keep = select(&intact, job.press, job.from, job.to, None);
    if keep.is_empty() {
        bail!("every segment was overwritten while copying");
    }
    if keep.len() < picked.len() {
        tracing::warn!(
            dropped = picked.len() - keep.len(),
            "segments overwritten while copying were left out"
        );
    }
    let kept_names: Vec<String> = keep
        .iter()
        .map(|k| names[picked.iter().position(|p| p == k).expect("kept from picked")].clone())
        .collect();
    let list = work.0.join("list.txt");
    fs::write(&list, concat_list(&kept_names)).context("writing concat list")?;

    let name = clip_name(job.stamp, job.kind);
    let mut out = dirs.raw.join(&name);
    let mut n = 2;
    while out.exists() {
        out = dirs.raw.join(numbered(&name, n));
        n += 1;
    }
    let part = out.with_file_name(format!(
        "{}.part",
        out.file_name().expect("has a name").to_string_lossy()
    ));
    if let Err(e) = concat(&list, &part) {
        let _ = fs::remove_file(&part);
        return Err(e);
    }
    fs::rename(&part, &out).with_context(|| format!("renaming to {}", out.display()))?;
    tracing::info!(
        clip = %out.display(),
        segments = keep.len(),
        secs = (keep[keep.len() - 1].end - keep[0].start) / 1000,
        full = job.kind == Kind::Full,
        "clip saved"
    );
    Ok(out)
}

/// Runs the concat ffmpeg at below-normal priority and waits for it.
pub fn run_concat(ffmpeg: &Path, job: &ChildJob, list: &Path, out: &Path) -> Result<()> {
    let mut child = job.spawn_logged_low(ffmpeg, &concat_args(list, out))?;
    let status = child.wait().context("waiting for concat ffmpeg")?;
    if !status.success() {
        bail!("concat ffmpeg exited with {status}");
    }
    Ok(())
}
```

```rust
pub enum SaverMsg {
    Press(Press),
    Shutdown,
}

pub struct SaverSetup {
    pub ffmpeg: PathBuf,
    pub job: Arc<ChildJob>,
    pub dirs: ClipDirs,
    pub session: SessionSlot,
    pub pre_roll: u32,
    pub post_roll: u32,

    pub on_saved: Box<dyn Fn(&Path) + Send>,
}

/// The saver thread: collects presses, waits out each clip's post-roll, saves one clip at a
/// time. Dropping it drops pending clips and waits for a save in progress.
pub struct Saver {
    tx: Sender<SaverMsg>,
    thread: Option<JoinHandle<()>>,
}

impl Saver {
    /// `tx` is the sending side of `rx`, kept to deliver `Shutdown`.
    pub fn start(setup: SaverSetup, tx: Sender<SaverMsg>, rx: Receiver<SaverMsg>) -> Result<Saver> {
        let thread = std::thread::Builder::new()
            .name("saver".into())
            .spawn(move || run(setup, rx))
            .context("spawning saver thread")?;
        Ok(Saver { tx, thread: Some(thread) })
    }
}

impl Drop for Saver {
    fn drop(&mut self) {
        let _ = self.tx.send(SaverMsg::Shutdown);
        if let Some(t) = self.thread.take()
            && t.join().is_err()
        {
            tracing::error!("saver thread panicked");
        }
    }
}

fn run(s: SaverSetup, rx: Receiver<SaverMsg>) {
    let mut sched = Scheduler::new(s.pre_roll, s.post_roll, s.buffer_secs);
    let concat = |list: &Path, out: &Path| run_concat(&s.ffmpeg, &s.job, list, out);
    loop {
        match rx.recv_timeout(Duration::from_millis(100)) {
            Ok(SaverMsg::Press(p)) => {
                let merged = sched.press(p);
                tracing::info!(kind = ?p.kind, merged, "clip hotkey");
            }
            Ok(SaverMsg::Shutdown) | Err(RecvTimeoutError::Disconnected) => break,
            Err(RecvTimeoutError::Timeout) => {}
        }
        for job in sched.due(wall_ms()) {
            wait_for_segments(&s.session, job.to);
            match save(&job, &s.session, &s.dirs, &concat) {
                Ok(path) => (s.on_saved)(&path),
                Err(e) => tracing::warn!(id = job.id, "clip not saved: {e:#}"),
            }
        }
    }
    if sched.pending() > 0 {
        tracing::info!(pending = sched.pending(), "quitting; pending clips dropped");
    }
}

/// Waits until the index lists a segment ending at or after `to` (the one holding the end of
/// the clip has closed), or until it can't be coming any more.
fn wait_for_segments(slot: &SessionSlot, to: Ms) {
    let give_up = to + 2 * SEGMENT_MS + 1_000;
    while let Some(s) = current(slot) {
        let segs = read_index(&s.buffer_dir, s.start);
        if segs.last().is_some_and(|x| x.end >= to) || wall_ms() >= give_up {
            return;
        }
        std::thread::sleep(Duration::from_millis(250));
    }
}
```

```rust
//! The press and saved cues, played asynchronously from memory.

use std::sync::LazyLock;

use retake_core::cue::{PRESS_CUE, SAVED_CUE, tone_wav};
use windows::Win32::Media::Audio::{PlaySoundW, SND_ASYNC, SND_MEMORY, SND_NODEFAULT};
use windows::core::PCWSTR;

static PRESS: LazyLock<Vec<u8>> = LazyLock::new(|| tone_wav(PRESS_CUE));
static SAVED: LazyLock<Vec<u8>> = LazyLock::new(|| tone_wav(SAVED_CUE));

fn play(wav: &'static [u8]) {
    // SAFETY: with SND_MEMORY the pointer is a whole WAV file in memory; it is 'static, so it
    // outlives the asynchronous playback.
    let ok = unsafe {
        PlaySoundW(PCWSTR(wav.as_ptr().cast()), None, SND_MEMORY | SND_ASYNC | SND_NODEFAULT)
    };
    if !ok.as_bool() {
        tracing::debug!("PlaySoundW failed");
    }
}

pub fn play_press() {
    play(PRESS.as_slice());
}

pub fn play_saved() {
    play(SAVED.as_slice());
}
```

```rust
fn look(s: TrayStatus, problem: Option<&str>) -> ([u8; 3], String) {
    const YELLOW: [u8; 3] = [234, 179, 8];

        TrayStatus::Idle => ([140, 140, 140], "Retake — idle"),
        TrayStatus::Recording => ([220, 38, 38], "Retake — recording"),
```
