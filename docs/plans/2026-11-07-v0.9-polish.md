# v0.9 Polish & daily use Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [ ]` for tracking.

**Goal:** Retake behaves like a finished background tool: one plain window (Status, Clips, Settings, About) plus the tray, start with Windows, config changes applied without a manual restart, readable messages, nothing popping up during a match.
**Architecture:** a global status board (`status.rs`) that the recorder, saver and queue write and the window and tray tooltip read; a notification queue (`notify.rs`) that holds toasts while the game runs; the window (`ui.rs`) is plain Win32 controls made with the `windows` crate on the tray thread (no new GUI dependency: `native-windows-gui` is unmaintained and built on `winapi`); Settings writes `config.toml` with `toml_edit` so comments stay.

## Decisions

- **Hot reload = a clean relaunch at a safe moment.** A changed, valid `config.toml` relaunches Retake (`--restarted`, which waits for the old instance's lock) when nothing is being recorded; during a match it waits for the match to end and says so. An invalid file keeps the old config running and toasts the error. Simpler and safer than re-wiring every component live; hotkeys therefore change after the match, not mid-match.
- **No toasts during a match:** queued until the game closes (rule 6: nothing drawn over the game).
- **Strict safety** (`[safety] strict = true`): forces device audio loopback (no game process id used) and skips reading the game's settings file.

## Tasks

1. `status.rs`: phase, game, fps, encoder, speed, buffer, disk free, clips today, warnings, last 10 events; written by recorder/saver/media.
2. `notify.rs`: toast queue gated on "game running".
3. Recorder: Pause/Resume (`Event::Pause`), status board updates.
4. Config: `[safety] strict`; `ui` keys none (window state isn't persisted).
5. `config_watch.rs`: poll `config.toml` mtime every second; validate; relaunch when safe.
6. `autostart.rs`: HKCU `Run` entry toggle; `--autostart` delays recording start by 30 s.
7. `ui.rs`: the window (tabs Status / Clips / Settings / About), tray left-click opens it, closing hides it.
8. Tray: Pause/Resume, Save last 60 s, Start with Windows ✓, Copy diagnostics; richer tooltip; exporting (blue) state.
9. Copy diagnostics: version, config with the user profile path anonymised, last 200 log lines → clipboard.
10. `cargo deny` in CI; doc comments pass.
